# 🌿 Untangle - Your Mental Wellness Companion

A gentle, evidence-based web application for exploring and reframing difficult thoughts using Cognitive Behavioral Therapy (CBT) principles.

## ✨ Features

### 🧠 Thought Untangler
A step-by-step guided journey to help you:
- Identify triggering situations
- Recognize automatic thoughts
- Name your emotions and their intensity
- Spot cognitive distortions (thinking traps)
- Examine evidence for and against thoughts
- Create balanced, realistic perspectives
- Track belief ratings in new thoughts

### 💙 Mood Check-In
- Quick emotional state tracking
- Visual mood selection
- Optional notes for context
- Historical mood tracking
- Pattern recognition over time

### 🌸 Calm Corner
Grounding exercises including:
- **Breathing Exercise**: Guided 4-2-4 breathing rhythm with visual cues
- **5-4-3-2-1 Grounding**: Sensory awareness technique
- **Affirmations**: Gentle reminders for difficult moments

### 📖 Journal
- Review all thought records and mood check-ins
- Track your progress with statistics
- Calculate activity streaks
- Export your data for backup
- Privacy-focused data management

## 🧰 Cognitive Distortions Addressed

1. **All-or-Nothing Thinking** - Black and white perspectives
2. **Catastrophizing** - Expecting the worst outcome
3. **Mind Reading** - Assuming what others think
4. **Overgeneralization** - One event means everything
5. **Personalization** - Blaming yourself for external events
6. **Should Statements** - Rigid rules about behavior
7. **Emotional Reasoning** - Feelings equal reality
8. **Fortune Telling** - Predicting negative outcomes

## 📊 Data Storage

All data is stored in browser LocalStorage:
- `thoughtRecords` - Array of thought record objects
- `moods` - Array of mood check-in objects
- `thoughtDraft` - Auto-saved work in progress

Maximum storage:
- Last 50 thought records
- Last 100 mood check-ins
- 1 draft in progress
